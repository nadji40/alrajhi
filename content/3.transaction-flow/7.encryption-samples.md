# Code Examples & Encryption

This section provides actual encryption and integration examples for Al Rajhi Bank Payment Gateway in multiple programming languages, based on the official documentation.

## Real Encryption Requirements 

According to the ARB Payment Gateway documentation:

- **Algorithm**: AES with CBC Mode
- **Padding**: PKCS5Padding  
- **Initialization Vector**: "PGKEYENCDECIVSPC"
- **URL Encoding**: Required before encryption
- **URL Decoding**: Required after decryption

## PHP Encryption Functions

### Basic Encryption Function
    
```php
<?php
/**
 * ARB Payment Gateway Encryption
 * Based on official documentation requirements
 */
function arbEncrypt($data, $resourceKey) {
    // Step 1: Convert data to JSON
    $jsonData = json_encode($data);
    
    // Step 2: URL encode (mandatory before encryption per document)
    $encodedData = urlencode($jsonData);
    
    // Step 3: Encrypt using AES with CBC Mode and PKCS5Padding
    // IV value  : "PGKEYENCDECIVSPC"
    $iv = "PGKEYENCDECIVSPC";
    $method = 'AES-256-CBC';
    
    $encrypted = openssl_encrypt(
        $encodedData,
        $method,
        $resourceKey,
        OPENSSL_RAW_DATA,
        $iv
    );
    
    // Step 4: Base64 encode for transmission
    return base64_encode($encrypted);
}

/**
 * ARB Payment Gateway Decryption
 * Based on official documentation requirements
 */
function arbDecrypt($encryptedData, $resourceKey) {
    // Step 1: Base64 decode
    $data = base64_decode($encryptedData);
    
    // Step 2: Decrypt using same parameters
    // IV value  : "PGKEYENCDECIVSPC"
    $iv = "PGKEYENCDECIVSPC";
    $method = 'AES-256-CBC';
    
    $decrypted = openssl_decrypt(
        $data,
        $method,
        $resourceKey,
        OPENSSL_RAW_DATA,
        $iv
    );
    
    // Step 3: URL decode (mandatory after decryption per document)
    $decodedData = urldecode($decrypted);
    
    // Step 4: Parse JSON
    return json_decode($decodedData, true);
}
```

## HTTP Request Example

```php
<?php
/**
 * Send request to ARB Payment Gateway
 * Note: Endpoint URLs are provided via email by Al Rajhi Bank
 */
function sendARBRequest($requestData, $endpointUrl) {
    $ch = curl_init();
    
    curl_setopt_array($ch, [
        CURLOPT_URL => $endpointUrl,
        CURLOPT_POST => true,
        CURLOPT_POSTFIELDS => json_encode($requestData),
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_SSL_VERIFYPEER => true,
        CURLOPT_HTTPHEADER => [
            'Content-Type: application/json'
        ]
    ]);
    
    $response = curl_exec($ch);
    $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    curl_close($ch);
    
    if ($httpCode !== 200) {
        throw new Exception("HTTP Error: " . $httpCode);
    }
    
    return json_decode($response, true);
}
```

```json
"errorText":" Problem occurred while validating transaction data",
"result": null

```

### Processing Response

```php
<?php
function processARBResponse($response, $resourceKey) {
    $responseData = json_decode($response, true);
    
    if ($responseData['status'] == '1') {
        // Success - extract payment ID and URL
        $result = $responseData['result'];
        list($paymentId, $paymentUrl) = explode(':', $result, 2);
        
        return [
            'success' => true,
            'paymentId' => $paymentId,
            'paymentUrl' => $paymentUrl
        ];
    } else {
        // Failure
        return [
            'success' => false,
            'error' => $responseData['error'],
            'errorText' => $responseData['errorText']
        ];
    }
}
```

## Callback Response Handling

### Final Response Format  

When ARB Payment Gateway sends the final response, it includes:

- **paymentId**: Unique payment ID
- **trandata**: Encrypted response data  
- **Error**: Error code (if any)
- **ErrorText**: Error description (if any)

### Processing Callback

```php
<?php
function handleARBCallback($callbackData, $resourceKey) {
    // Check if we have encrypted transaction data
    if (isset($callbackData['trandata']) && !empty($callbackData['trandata'])) {
        // Decrypt the response
        $decryptedData = arbDecrypt($callbackData['trandata'], $resourceKey);
        
        // Check transaction result
        $result = $decryptedData['result'] ?? '';
        $isSuccess = in_array($result, ['CAPTURED', 'APPROVED']);
        
        return [
            'success' => $isSuccess,
            'result' => $result,
            'transactionId' => $decryptedData['transId'] ?? '',
            'amount' => $decryptedData['amt'] ?? '',
            'trackId' => $decryptedData['trackId'] ?? '',
            'paymentId' => $callbackData['paymentId'] ?? ''
        ];
    } else {
        // Handle error response
        return [
            'success' => false,
            'error' => $callbackData['ErrorText'] ?? 'Payment failed',
            'errorCode' => $callbackData['Error'] ?? 'UNKNOWN'
        ];
    }
}

// Usage
$result = handleARBCallback($_POST, "YOUR_RESOURCE_KEY");

if ($result['success']) {
    echo "Payment successful! Transaction ID: " . $result['transactionId'];
} else {
    echo "Payment failed: " . $result['error'];
}
```

## JavaScript Examples

### Node.js Encryption Functions

```javascript
const crypto = require('crypto');

/**
 * ARB Payment Gateway Encryption for Node.js
 * Based on official documentation requirements
 */
function arbEncrypt(data, resourceKey) {
    // Step 1: Convert to JSON
    const jsonData = JSON.stringify(data);
    
    // Step 2: URL encode (mandatory before encryption per document)
    const encodedData = encodeURIComponent(jsonData);
    
    // Step 3: Encrypt using AES-256-CBC with official IV
    const iv = "PGKEYENCDECIVSPC"; // Official IV from document
    const cipher = crypto.createCipher('aes-256-cbc', resourceKey);
    
    let encrypted = cipher.update(encodedData, 'utf8', 'base64');
    encrypted += cipher.final('base64');
    
    return encrypted;
}

// Usage example
const trandata = {
    amt: "100.00",
    action: "1",  // Purchase
    password: "YOUR_TRANPORTAL_PASSWORD",
    id: "YOUR_TRANPORTAL_ID",
    currencyCode: "682",  // SAR
    trackId: "ORDER_" + Date.now(),
    responseURL: "https://yourdomain/callback"
};

const encrypted = arbEncrypt(trandata, "YOUR_RESOURCE_KEY");
```

## Important Notes

::callout{icon="i-lucide-alert-triangle" color="amber"}
**From ARB Documentation:**
- Endpoint URLs are provided via email by Al Rajhi Bank
- Use initialization vector "PGKEYENCDECIVSPC" for encryption
- URL encoding is mandatory before encryption
- URL decoding is mandatory after decryption
- Test in sandbox environment before production
::

::callout{icon="i-lucide-info" color="blue"}
**Integration Requirements:**
- Tranportal ID and Password (from merchant portal)
- Resource Key (provided via secure email)
- HTTPS required for all payment pages
- Proper error handling and logging
- **Any programming language** can be used as long as it supports AES-256-CBC encryption
