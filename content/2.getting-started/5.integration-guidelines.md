# Integration Guidelines

This section outlines the mandatory steps that must be followed by the Merchant Integration Team to ensure successful and secure integration with Al Rajhi Bank Payment Gateway.

## Mandatory Integration Steps

All merchant integration teams must follow these essential steps in the specified order:

::steps
### Verify API Endpoints
Send test requests using Postman or similar tools to verify endpoint connectivity and basic functionality.

### Frame JSON Requests
Create properly formatted JSON requests with all required parameters as specified in the documentation.

### Implement Encryption
Encrypt the plain JSON request using the Resource Key received via email from Al Rajhi Bank.

### Send Encrypted Requests
Frame the encrypted request and send it to the ARB Payment Gateway endpoint URL shared via email.

### Handle Responses
Decrypt the encrypted response data using the resource key and process the plain response message.

### Implement Status Verification
Always verify transaction status using the inquiry API after receiving payment responses.
::

## Step-by-Step Implementation Guide

### Step 1: Endpoint Verification

Before implementing your integration, verify all API endpoints:

```php
<?php
/**
 * Endpoint verification for ARB Payment Gateway
 * Note: Specific endpoint URLs are provided via secure email by Al Rajhi Bank
 */
function verifyARBEndpoint($endpointUrl) {
    $ch = curl_init();
    curl_setopt_array($ch, [
        CURLOPT_URL => $endpointUrl,
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_TIMEOUT => 10,
        CURLOPT_NOBODY => true, // HEAD request only
        CURLOPT_SSL_VERIFYPEER => true
    ]);
    
    $response = curl_exec($ch);
    $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $error = curl_error($ch);
    curl_close($ch);
    
    return [
        'accessible' => $httpCode !== 0 && empty($error),
        'http_code' => $httpCode,
        'error' => $error,
        'url' => $endpointUrl
    ];
}

// Usage example - Test endpoint connectivity
// Production base URL: https://digitalpayments.alrajhibank.com.sa
// Specific endpoints provided via email by Al Rajhi Bank
$testEndpoint = "https://digitalpayments.alrajhibank.com.sa/YOUR_ENDPOINT_PATH";
$result = verifyARBEndpoint($testEndpoint);

echo "Endpoint Status: " . ($result['accessible'] ? 'OK' : 'FAILED') . "\n";
echo "HTTP Code: {$result['http_code']}\n";
if (!empty($result['error'])) {
    echo "Error: {$result['error']}\n";
}
```

### Step 2: JSON Request Formation

Create properly structured JSON requests with all required parameters:

```php
<?php
/**
 * Build ARB Payment Gateway requests based on official documentation
 */

// Build payment request (based on document structure)
function buildARBPaymentRequest($params) {
    // Validate required fields
    $required = ['amt', 'password', 'id', 'trackId', 'responseURL'];
    foreach ($required as $field) {
        if (!isset($params[$field]) || empty($params[$field])) {
            throw new InvalidArgumentException("Missing required field: {$field}");
        }
    }
    
    $request = [
        'amt' => $params['amt'],
        'action' => $params['action'] ?? '1', // 1 = Purchase
        'password' => $params['password'],
        'id' => $params['id'],
        'currencyCode' => $params['currencyCode'] ?? '682', // SAR
        'trackId' => $params['trackId'],
        'responseURL' => $params['responseURL'],
        'errorURL' => $params['errorURL'] ?? $params['responseURL']
    ];
    
    // Add optional fields if provided
    $optionalFields = ['udf1', 'udf2', 'udf3', 'udf4', 'udf5'];
    foreach ($optionalFields as $field) {
        if (isset($params[$field]) && !empty($params[$field])) {
            $request[$field] = $params[$field];
        }
    }
    
    return $request;
}
```

### Step 3: Encryption Implementation

Implement proper encryption using the Resource Key:

```php
<?php
/**
 * ARB Payment Gateway Encryption (Based on Official Documentation)
 * Uses AES algorithm with CBC Mode, PKCS5Padding
 * Initialization vector: "PGKEYENCDECIVSPC" (from document)
 */

function arbEncryptData($data, $resourceKey) {
    // Step 1: Convert to JSON
    $jsonData = json_encode($data);
    if (json_last_error() !== JSON_ERROR_NONE) {
        throw new Exception('JSON encoding failed: ' . json_last_error_msg());
    }
    
    // Step 2: URL encode (mandatory before encryption per document)
    $encodedData = urlencode($jsonData);
    
    // Step 3: Encrypt using AES-256-CBC with official IV
    $iv = "PGKEYENCDECIVSPC"; // Official IV from document
    $encrypted = openssl_encrypt(
        $encodedData,
        'AES-256-CBC',
        $resourceKey,
        OPENSSL_RAW_DATA,
        $iv
    );
    
    if ($encrypted === false) {
        throw new Exception('Encryption failed: ' . openssl_error_string());
    }
    
    // Step 4: Base64 encode for transmission
    return base64_encode($encrypted);
}

function arbDecryptData($encryptedData, $resourceKey) {
    // Step 1: Base64 decode
    $data = base64_decode($encryptedData);
    if ($data === false) {
        throw new Exception('Base64 decoding failed');
    }
    
    // Step 2: Decrypt using AES-256-CBC with official IV
    $iv = "PGKEYENCDECIVSPC"; // Official IV from document
    $decrypted = openssl_decrypt(
        $data,
        'AES-256-CBC',
        $resourceKey,
        OPENSSL_RAW_DATA,
        $iv
    );
    
    if ($decrypted === false) {
        throw new Exception('Decryption failed: ' . openssl_error_string());
    }
    
    // Step 3: URL decode (mandatory after decryption per document)
    $decodedData = urldecode($decrypted);
    
    // Step 4: Parse JSON
    $result = json_decode($decodedData, true);
    if (json_last_error() !== JSON_ERROR_NONE) {
        throw new Exception('JSON decoding failed: ' . json_last_error_msg());
    }
    
    return $result;
}

// Usage example
$paymentData = [
    'amt' => '100.00',
    'action' => '1',
    'password' => 'YOUR_TRANPORTAL_PASSWORD',
    'id' => 'YOUR_TRANPORTAL_ID',
    'currencyCode' => '682',
    'trackId' => 'ORDER_' . time(),
    'responseURL' => 'https://yoursite.com/callback.php'
];

$encryptedData = arbEncryptData($paymentData, 'YOUR_RESOURCE_KEY');
```

### Step 4: Request Transmission

Send encrypted requests to ARB Payment Gateway:

```php
<?php
/**
 * Send HTTP request to ARB Payment Gateway
 * Note: Endpoint URLs are provided via secure email by Al Rajhi Bank
 */
function sendARBRequest($requestData, $endpointUrl) {
    $ch = curl_init();
    curl_setopt_array($ch, [
        CURLOPT_URL => $endpointUrl,
        CURLOPT_POST => true,
        CURLOPT_POSTFIELDS => json_encode($requestData),
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_TIMEOUT => 30,
        CURLOPT_CONNECTTIMEOUT => 10,
        CURLOPT_SSL_VERIFYPEER => true,
        CURLOPT_SSL_VERIFYHOST => 2,
        CURLOPT_HTTPHEADER => [
            'Content-Type: application/json',
            'Accept: application/json'
        ]
    ]);
    
    $response = curl_exec($ch);
    $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $error = curl_error($ch);
    curl_close($ch);
    
    // Handle cURL errors
    if ($error) {
        throw new Exception("HTTP request failed: {$error}");
    }
    
    // Handle HTTP errors
    if ($httpCode < 200 || $httpCode >= 300) {
        throw new Exception("HTTP error {$httpCode}: {$response}");
    }
    
    // Parse JSON response
    $responseData = json_decode($response, true);
    if (json_last_error() !== JSON_ERROR_NONE) {
        throw new Exception("Invalid JSON response: {$response}");
    }
    
    return $responseData;
}

// Usage example
$requestData = [
    'id' => 'YOUR_TRANPORTAL_ID',
    'trandata' => $encryptedData,
    'responseURL' => 'https://yoursite.com/callback.php',
    'errorURL' => 'https://yoursite.com/callback.php'
];

$endpointUrl = 'https://digitalpayments.alrajhibank.com.sa/YOUR_ENDPOINT_PATH';
$response = sendARBRequest($requestData, $endpointUrl);
```

### Step 5: Response Processing

Handle and decrypt responses properly:

```php
<?php
/**
 * Process ARB Payment Gateway responses based on official documentation
 */
function processARBResponse($response, $resourceKey) {
    try {
        // Check if response contains encrypted data
        if (isset($response['trandata']) && !empty($response['trandata'])) {
            $decryptedData = arbDecryptData($response['trandata'], $resourceKey);
            
            return [
                'success' => true,
                'encrypted' => true,
                'data' => $decryptedData,
                'raw_response' => $response
            ];
        }
        
        // Handle status responses (from document format)
        if (isset($response['status'])) {
            if ($response['status'] === '1') {
                // Success response
                return [
                    'success' => true,
                    'encrypted' => false,
                    'result' => $response['result'] ?? null,
                    'raw_response' => $response
                ];
            } else {
                // Error response
                return [
                    'success' => false,
                    'encrypted' => false,
                    'error_code' => $response['error'] ?? 'UNKNOWN',
                    'error_text' => $response['errorText'] ?? 'Unknown error occurred',
                    'raw_response' => $response
                ];
            }
        }
        
        // Handle direct error responses
        if (isset($response['error']) || isset($response['ErrorText'])) {
            return [
                'success' => false,
                'encrypted' => false,
                'error_code' => $response['error'] ?? 'UNKNOWN',
                'error_text' => $response['ErrorText'] ?? 'Unknown error occurred',
                'raw_response' => $response
            ];
        }
        
        // Unknown response format
        return [
            'success' => false,
            'encrypted' => false,
            'error_code' => 'INVALID_RESPONSE',
            'error_text' => 'Unknown response format',
            'raw_response' => $response
        ];
        
    } catch (Exception $e) {
        return [
            'success' => false,
            'encrypted' => false,
            'error_code' => 'PROCESSING_ERROR',
            'error_text' => 'Response processing failed: ' . $e->getMessage(),
            'raw_response' => $response
        ];
    }
}
```

## Security Best Practices

### Data Protection

1. **Never log sensitive data** such as card numbers, CVV, or Resource Keys
2. **Use HTTPS for all communications** with the payment gateway
3. **Validate all input data** before processing
4. **Implement proper session management** for payment flows
5. **Store credentials securely** using environment variables or secure vaults

### Error Handling

```php
<?php
/**
 * Simple error logging for ARB Payment Gateway
 */
function logARBError($level, $message, $context = []) {
    // Sanitize sensitive data
    $sensitiveFields = ['password', 'card_number', 'cvv', 'resource_key'];
    
    array_walk_recursive($context, function(&$value, $key) use ($sensitiveFields) {
        if (in_array(strtolower($key), $sensitiveFields)) {
            $value = is_string($value) && strlen($value) > 4 
                ? substr($value, 0, 4) . str_repeat('*', strlen($value) - 4)
                : '***MASKED***';
        }
    });
    
    $logEntry = [
        'timestamp' => date('Y-m-d H:i:s'),
        'level' => $level,
        'message' => $message,
        'context' => $context
    ];
    
    error_log(json_encode($logEntry), 3, 'arb_payment.log');
}

// Usage
logARBError('ERROR', 'Payment failed', ['error_code' => 'IPAY001', 'amount' => '100.00']);
```

## Testing and Validation

### Integration Testing Checklist

- [ ] **Endpoint Connectivity**: All API endpoints are accessible
- [ ] **Request Formation**: JSON requests are properly formatted
- [ ] **Encryption/Decryption**: Data encryption works correctly
- [ ] **Error Handling**: All error scenarios are handled gracefully
- [ ] **Response Processing**: All response types are processed correctly
- [ ] **Security Validation**: No sensitive data is logged or exposed
- [ ] **Performance Testing**: Response times are within acceptable limits

### Simple Integration Testing

```php
<?php
/**
 * Simple integration testing functions for ARB Payment Gateway
 */

function testARBEncryption($resourceKey) {
    try {
        $testData = ['test' => 'data', 'amount' => '100.00'];
        $encrypted = arbEncryptData($testData, $resourceKey);
        $decrypted = arbDecryptData($encrypted, $resourceKey);
        
        return [
            'success' => $testData === $decrypted,
            'message' => 'Encryption/decryption test completed'
        ];
    } catch (Exception $e) {
        return [
            'success' => false,
            'message' => 'Encryption test failed: ' . $e->getMessage()
        ];
    }
}

function testARBEndpoint($endpointUrl) {
    $result = verifyARBEndpoint($endpointUrl);
    return [
        'success' => $result['accessible'],
        'message' => $result['accessible'] ? 'Endpoint accessible' : 'Endpoint failed: ' . $result['error']
    ];
}

function runARBIntegrationTests($resourceKey, $endpointUrl) {
    $results = [
        'encryption_test' => testARBEncryption($resourceKey),
        'endpoint_test' => testARBEndpoint($endpointUrl)
    ];
    
    $overallSuccess = array_reduce($results, function($carry, $result) {
        return $carry && $result['success'];
    }, true);
    
    return [
        'overall_success' => $overallSuccess,
        'individual_results' => $results,
        'timestamp' => date('Y-m-d H:i:s')
    ];
}
```
