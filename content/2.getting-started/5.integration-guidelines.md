# Integration Guidelines

This section outlines the mandatory steps that must be followed by the Merchant Integration Team to ensure successful and secure integration with Al Rajhi Bank Payment Gateway.

## Mandatory Integration Steps

All merchant integration teams must follow these essential steps in the specified order:

::steps
### Verify API Endpoints
Send test requests using Postman or similar tools to verify endpoint connectivity and basic functionality.

### Frame JSON Requests
Create properly formatted JSON requests with all required parameters as specified in the documentation.

### Implement Encryption
Encrypt the plain JSON request using the Resource Key received via email from Al Rajhi Bank.

### Send Encrypted Requests
Frame the encrypted request and send it to the ARB Payment Gateway endpoint URL shared via email.

### Handle Responses
Decrypt the encrypted response data using the resource key and process the plain response message.

### Implement Status Verification
Always verify transaction status using the inquiry API after receiving payment responses.
::

## Step-by-Step Implementation Guide

### Step 1: Endpoint Verification

Before implementing your integration, verify all API endpoints:

```php
// Example: Endpoint verification script
class EndpointVerifier {
    private $baseUrl;
    private $endpoints;
    
    public function __construct($environment = 'sandbox') {
        $this->baseUrl = $environment === 'production' 
            ? 'https://digitalpayments.alrajhibank.com.sa'
            : 'https://sandbox.digitalpayments.alrajhibank.com.sa';
            
        $this->endpoints = [
            'payment_token' => '/pg/payment/tranportal/api/paymentToken.htm',
            'transaction_status' => '/pg/payment/tranportal/api/transactionStatus.htm',
            'refund' => '/pg/payment/tranportal/api/refund.htm',
            'inquiry' => '/pg/payment/tranportal/api/inquiry.htm'
        ];
    }
    
    /**
     * Verify all endpoints are accessible
     */
    public function verifyEndpoints() {
        $results = [];
        
        foreach ($this->endpoints as $name => $endpoint) {
            $url = $this->baseUrl . $endpoint;
            $results[$name] = $this->checkEndpoint($url);
        }
        
        return $results;
    }
    
    private function checkEndpoint($url) {
        $ch = curl_init();
        curl_setopt_array($ch, [
            CURLOPT_URL => $url,
            CURLOPT_RETURNTRANSFER => true,
            CURLOPT_TIMEOUT => 10,
            CURLOPT_NOBODY => true, // HEAD request only
            CURLOPT_SSL_VERIFYPEER => true
        ]);
        
        $response = curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        $error = curl_error($ch);
        curl_close($ch);
        
        return [
            'accessible' => $httpCode !== 0 && empty($error),
            'http_code' => $httpCode,
            'error' => $error,
            'url' => $url
        ];
    }
}

// Usage
$verifier = new EndpointVerifier('sandbox');
$results = $verifier->verifyEndpoints();

foreach ($results as $endpoint => $result) {
    echo "Endpoint: {$endpoint}\n";
    echo "Status: " . ($result['accessible'] ? 'OK' : 'FAILED') . "\n";
    echo "HTTP Code: {$result['http_code']}\n";
    if (!empty($result['error'])) {
        echo "Error: {$result['error']}\n";
    }
    echo "---\n";
}
```

### Step 2: JSON Request Formation

Create properly structured JSON requests with all required parameters:

```php
// Example: Request builder with validation
class ARBRequestBuilder {
    private $requiredFields = [
        'payment_token' => ['amt', 'action', 'password', 'id', 'currencyCode', 'trackId', 'responseURL', 'errorURL'],
        'transaction_status' => ['password', 'id', 'paymentId', 'action'],
        'refund' => ['password', 'id', 'action', 'amt', 'currencyCode', 'trackId', 'transId']
    ];
    
    /**
     * Build and validate payment token request
     */
    public function buildPaymentTokenRequest($params) {
        $this->validateRequiredFields($params, 'payment_token');
        
        $request = [
            'amt' => $params['amt'],
            'action' => $params['action'] ?? '1',
            'password' => $params['password'],
            'id' => $params['id'],
            'currencyCode' => $params['currencyCode'] ?? '682',
            'trackId' => $params['trackId'],
            'responseURL' => $params['responseURL'],
            'errorURL' => $params['errorURL'] ?? $params['responseURL']
        ];
        
        // Add optional fields
        $optionalFields = ['udf1', 'udf2', 'udf3', 'udf4', 'udf5', 'langid'];
        foreach ($optionalFields as $field) {
            if (isset($params[$field]) && !empty($params[$field])) {
                $request[$field] = $params[$field];
            }
        }
        
        return $request;
    }
    
    /**
     * Build transaction status inquiry request
     */
    public function buildStatusInquiryRequest($params) {
        $this->validateRequiredFields($params, 'transaction_status');
        
        return [
            'password' => $params['password'],
            'id' => $params['id'],
            'paymentId' => $params['paymentId'],
            'action' => '10' // Inquiry action
        ];
    }
    
    /**
     * Build refund request
     */
    public function buildRefundRequest($params) {
        $this->validateRequiredFields($params, 'refund');
        
        return [
            'password' => $params['password'],
            'id' => $params['id'],
            'action' => '2', // Refund action
            'amt' => $params['amt'],
            'currencyCode' => $params['currencyCode'] ?? '682',
            'trackId' => $params['trackId'],
            'transId' => $params['transId']
        ];
    }
    
    private function validateRequiredFields($params, $requestType) {
        $required = $this->requiredFields[$requestType];
        $missing = [];
        
        foreach ($required as $field) {
            if (!isset($params[$field]) || empty($params[$field])) {
                $missing[] = $field;
            }
        }
        
        if (!empty($missing)) {
            throw new InvalidArgumentException(
                "Missing required fields for {$requestType}: " . implode(', ', $missing)
            );
        }
    }
}
```

### Step 3: Encryption Implementation

Implement proper encryption using the Resource Key:

```php
// Example: Encryption service with validation
class ARBEncryptionService {
    private $resourceKey;
    private $algorithm = 'AES-256-CBC';
    
    public function __construct($resourceKey) {
        $this->validateResourceKey($resourceKey);
        $this->resourceKey = $resourceKey;
    }
    
    /**
     * Encrypt request data
     */
    public function encryptRequest($data) {
        // Step 1: Convert to JSON
        $jsonData = json_encode($data);
        if (json_last_error() !== JSON_ERROR_NONE) {
            throw new Exception('JSON encoding failed: ' . json_last_error_msg());
        }
        
        // Step 2: URL encode (mandatory before encryption)
        $encodedData = urlencode($jsonData);
        
        // Step 3: Encrypt using AES-256-CBC
        $iv = substr($this->resourceKey, 0, 16);
        $encrypted = openssl_encrypt(
            $encodedData,
            $this->algorithm,
            $this->resourceKey,
            OPENSSL_RAW_DATA,
            $iv
        );
        
        if ($encrypted === false) {
            throw new Exception('Encryption failed: ' . openssl_error_string());
        }
        
        // Step 4: Base64 encode for transmission
        return base64_encode($encrypted);
    }
    
    /**
     * Decrypt response data
     */
    public function decryptResponse($encryptedData) {
        // Step 1: Base64 decode
        $data = base64_decode($encryptedData);
        if ($data === false) {
            throw new Exception('Base64 decoding failed');
        }
        
        // Step 2: Decrypt using AES-256-CBC
        $iv = substr($this->resourceKey, 0, 16);
        $decrypted = openssl_decrypt(
            $data,
            $this->algorithm,
            $this->resourceKey,
            OPENSSL_RAW_DATA,
            $iv
        );
        
        if ($decrypted === false) {
            throw new Exception('Decryption failed: ' . openssl_error_string());
        }
        
        // Step 3: URL decode (mandatory after decryption)
        $decodedData = urldecode($decrypted);
        
        // Step 4: Parse JSON
        $result = json_decode($decodedData, true);
        if (json_last_error() !== JSON_ERROR_NONE) {
            throw new Exception('JSON decoding failed: ' . json_last_error_msg());
        }
        
        return $result;
    }
    
    private function validateResourceKey($key) {
        if (empty($key)) {
            throw new InvalidArgumentException('Resource key cannot be empty');
        }
        
        if (strlen($key) < 16) {
            throw new InvalidArgumentException('Resource key must be at least 16 characters long');
        }
    }
}
```

### Step 4: Request Transmission

Send encrypted requests to ARB Payment Gateway:

```php
// Example: HTTP client with proper error handling
class ARBHttpClient {
    private $baseUrl;
    private $timeout;
    private $connectTimeout;
    
    public function __construct($baseUrl, $timeout = 30, $connectTimeout = 10) {
        $this->baseUrl = rtrim($baseUrl, '/');
        $this->timeout = $timeout;
        $this->connectTimeout = $connectTimeout;
    }
    
    /**
     * Send encrypted request to ARB Payment Gateway
     */
    public function sendRequest($endpoint, $requestData) {
        $url = $this->baseUrl . $endpoint;
        
        $ch = curl_init();
        curl_setopt_array($ch, [
            CURLOPT_URL => $url,
            CURLOPT_POST => true,
            CURLOPT_POSTFIELDS => json_encode($requestData),
            CURLOPT_RETURNTRANSFER => true,
            CURLOPT_TIMEOUT => $this->timeout,
            CURLOPT_CONNECTTIMEOUT => $this->connectTimeout,
            CURLOPT_SSL_VERIFYPEER => true,
            CURLOPT_SSL_VERIFYHOST => 2,
            CURLOPT_HTTPHEADER => [
                'Content-Type: application/json',
                'Accept: application/json',
                'User-Agent: ARB-PHP-SDK/1.0'
            ]
        ]);
        
        $response = curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        $error = curl_error($ch);
        $info = curl_getinfo($ch);
        curl_close($ch);
        
        // Handle cURL errors
        if ($error) {
            throw new Exception("HTTP request failed: {$error}");
        }
        
        // Handle HTTP errors
        if ($httpCode < 200 || $httpCode >= 300) {
            throw new Exception("HTTP error {$httpCode}: {$response}");
        }
        
        // Parse JSON response
        $responseData = json_decode($response, true);
        if (json_last_error() !== JSON_ERROR_NONE) {
            throw new Exception("Invalid JSON response: {$response}");
        }
        
        return [
            'data' => $responseData,
            'http_code' => $httpCode,
            'response_time' => $info['total_time'],
            'raw_response' => $response
        ];
    }
}
```

### Step 5: Response Processing

Handle and decrypt responses properly:

```php
// Example: Response processor with comprehensive error handling
class ARBResponseProcessor {
    private $encryptionService;
    
    public function __construct($encryptionService) {
        $this->encryptionService = $encryptionService;
    }
    
    /**
     * Process payment gateway response
     */
    public function processResponse($response) {
        try {
            // Check if response contains encrypted data
            if (isset($response['trandata']) && !empty($response['trandata'])) {
                $decryptedData = $this->encryptionService->decryptResponse($response['trandata']);
                
                return [
                    'success' => true,
                    'encrypted' => true,
                    'data' => $decryptedData,
                    'raw_response' => $response
                ];
            }
            
            // Handle error responses
            if (isset($response['error']) || isset($response['ErrorText'])) {
                return [
                    'success' => false,
                    'encrypted' => false,
                    'error_code' => $response['error'] ?? 'UNKNOWN',
                    'error_text' => $response['ErrorText'] ?? 'Unknown error occurred',
                    'raw_response' => $response
                ];
            }
            
            // Handle status responses
            if (isset($response['status'])) {
                return [
                    'success' => $response['status'] === '1',
                    'encrypted' => false,
                    'status' => $response['status'],
                    'data' => $response,
                    'raw_response' => $response
                ];
            }
            
            // Unknown response format
            return [
                'success' => false,
                'encrypted' => false,
                'error_code' => 'INVALID_RESPONSE',
                'error_text' => 'Unknown response format',
                'raw_response' => $response
            ];
            
        } catch (Exception $e) {
            return [
                'success' => false,
                'encrypted' => false,
                'error_code' => 'PROCESSING_ERROR',
                'error_text' => 'Response processing failed: ' . $e->getMessage(),
                'raw_response' => $response
            ];
        }
    }
}
```

## Security Best Practices

### Data Protection

1. **Never log sensitive data** such as card numbers, CVV, or Resource Keys
2. **Use HTTPS for all communications** with the payment gateway
3. **Validate all input data** before processing
4. **Implement proper session management** for payment flows
5. **Store credentials securely** using environment variables or secure vaults

### Error Handling

```php
// Example: Secure error logging
class SecureLogger {
    private $logFile;
    private $sensitiveFields = ['password', 'card_number', 'cvv', 'resource_key'];
    
    public function __construct($logFile) {
        $this->logFile = $logFile;
    }
    
    /**
     * Log data while masking sensitive information
     */
    public function logSecurely($level, $message, $context = []) {
        $sanitizedContext = $this->sanitizeContext($context);
        
        $logEntry = [
            'timestamp' => date('Y-m-d H:i:s'),
            'level' => $level,
            'message' => $message,
            'context' => $sanitizedContext
        ];
        
        file_put_contents(
            $this->logFile,
            json_encode($logEntry) . "\n",
            FILE_APPEND | LOCK_EX
        );
    }
    
    private function sanitizeContext($context) {
        array_walk_recursive($context, function(&$value, $key) {
            if (in_array(strtolower($key), $this->sensitiveFields)) {
                $value = $this->maskSensitiveData($value);
            }
        });
        
        return $context;
    }
    
    private function maskSensitiveData($value) {
        if (is_string($value) && strlen($value) > 4) {
            return substr($value, 0, 4) . str_repeat('*', strlen($value) - 4);
        }
        return '***MASKED***';
    }
}
```
