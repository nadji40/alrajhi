# Test Instruments

ARB Payment Gateway provides a comprehensive sandbox environment for testing your integration before going live. This section covers all the test credentials and instruments you'll need for development and testing.

## Sandbox Environment

ARB Payment Gateway APIs are complete RESTful APIs that can be thoroughly tested in the sandbox environment before deployment to the live environment.

::callout{icon="i-lucide-info" color="blue"}
**Important**: Always test your integration thoroughly in the sandbox environment before requesting access to the production environment.
::

### Environment URLs

```php
class ARBEnvironment {
    const SANDBOX_BASE_URL = 'https://sandbox.digitalpayments.alrajhibank.com.sa';
    const PRODUCTION_BASE_URL = 'https://digitalpayments.alrajhibank.com.sa';
    
    public static function getBaseUrl($environment = 'sandbox') {
        return $environment === 'production' 
            ? self::PRODUCTION_BASE_URL 
            : self::SANDBOX_BASE_URL;
    }
}
```

## Testing Integration

### Step-by-Step Testing Process

::steps
### Verify Endpoints
Test API endpoints using Postman or similar tools to ensure connectivity and basic functionality.

### Frame JSON Requests
Create properly formatted JSON requests with all required parameters as specified in the documentation.

### Test Encryption
Encrypt your test requests using the Resource Key to ensure encryption/decryption works correctly.

### Send Test Requests
Submit encrypted requests to the ARB Payment Gateway sandbox endpoints.

### Decrypt Responses
Decrypt and process response messages to verify proper handling of both success and error scenarios.

### Validate Transaction Flow
Test the complete transaction flow from payment initiation to final status verification.
::

### PHP Testing Framework

```php
class ARBTestSuite {
    private $gateway;
    private $testResults = [];
    
    public function __construct($credentials) {
        $this->gateway = new ARBPaymentGateway($credentials);
    }
    
    /**
     * Run comprehensive test suite
     */
    public function runTests() {
        $this->testSuccessfulPayment();
        $this->testFailedPayment();
        $this->testRefund();
        $this->testInquiry();
        
        return $this->generateReport();
    }
    
    /**
     * Test successful payment scenario
     */
    private function testSuccessfulPayment() {
        $testCard = ARBTestCards::getTestCard('visa_credit');
        
        try {
            $response = $this->gateway->createPaymentToken([
                'amt' => '100.00',
                'currency' => 'SAR',
                'action' => '1',
                'responseURL' => 'https://yoursite.com/callback'
            ]);
            
            $this->testResults['successful_payment'] = [
                'status' => 'PASS',
                'response' => $response
            ];
        } catch (Exception $e) {
            $this->testResults['successful_payment'] = [
                'status' => 'FAIL',
                'error' => $e->getMessage()
            ];
        }
    }
    
    /**
     * Generate test report
     */
    private function generateReport() {
        $passed = count(array_filter($this->testResults, function($result) {
            return $result['status'] === 'PASS';
        }));
        
        return [
            'total_tests' => count($this->testResults),
            'passed' => $passed,
            'failed' => count($this->testResults) - $passed,
            'results' => $this->testResults
        ];
    }
}
```

## Testing Checklist

Before moving to production, ensure you've tested:

- [ ] **Payment Token Generation** - Successful token creation
- [ ] **Payment Processing** - Complete payment flow
- [ ] **Transaction Status** - Status inquiry and verification
- [ ] **Error Handling** - Various error scenarios
- [ ] **Refunds** - Refund processing and confirmation
- [ ] **Webhooks** - Callback URL handling
- [ ] **Encryption/Decryption** - Data security validation
- [ ] **Mobile Compatibility** - Mobile device testing
- [ ] **3D Secure** - Authentication flow testing
- [ ] **Multiple Payment Methods** - Different card types and wallets
