## Testing Requirements (From Document)

### Mandatory Testing Steps
According to the ARB Payment Gateway documentation, merchants must:

1. **Verify Endpoints** - Test API connectivity (URLs provided via email)
2. **Frame JSON Requests** - Create properly formatted requests
3. **Encrypt with Resource Key** - Test encryption/decryption
4. **Send Requests** - Submit to ARB Payment Gateway
5. **Decrypt Responses** - Process returned messages
6. **Process Messages** - Handle success and error scenarios

## Integration Testing Process

### Step-by-Step Testing (From Document)

::steps
### Verify Endpoints
Test API endpoints connectivity (URLs provided via secure email by Al Rajhi Bank).

### Frame JSON Requests  
Create properly formatted JSON requests following the exact structure shown in the documentation.

### Encrypt with Resource Key
Encrypt your test requests using AES-256-CBC with the provided Resource Key and IV "PGKEYENCDECIVSPC".

### Send Test Requests
Submit encrypted requests to the ARB Payment Gateway test endpoints.

### Decrypt Responses
Decrypt and process response messages using the same Resource Key.

### Process Messages
Handle both success and error scenarios as documented.
::

### Test Credentials Access

According to the ARB Payment Gateway documentation:

- **Tranportal ID**: Provided after merchant onboarding
- **Tranportal Password**: Provided after merchant onboarding  
- **Resource Key**: Shared via secure email
- **Test URLs**: Shared via secure email (not publicly documented)

### Test Environment Setup

```php
<?php
// Test configuration (replace with your actual test credentials)
$testConfig = [
    'tranportal_id' => 'YOUR_TEST_TRANPORTAL_ID',
    'tranportal_password' => 'YOUR_TEST_PASSWORD', 
    'resource_key' => 'YOUR_TEST_RESOURCE_KEY',
    'test_endpoint_url' => 'PROVIDED_VIA_EMAIL'  // Not publicly available
];

// Test encryption with official IV
function testEncryption($data, $resourceKey) {
    $iv = "PGKEYENCDECIVSPC";  // Official IV from document
    $jsonData = json_encode($data);
    $encodedData = urlencode($jsonData);
    
    $encrypted = openssl_encrypt(
        $encodedData,
        'AES-256-CBC',
        $resourceKey,
        OPENSSL_RAW_DATA,
        $iv
    );
    
    return base64_encode($encrypted);
}
```
