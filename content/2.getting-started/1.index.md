# Getting Started

This section provides essential information to help you begin your integration with Al Rajhi Bank Payment Gateway. Follow these steps to set up your development environment and understand the core concepts.

## Overview

Al Rajhi Bank Payment Gateway offers a secure, PCI-DSS compliant solution for processing various payment methods including:

- **Debit Cards** - Visa, MasterCard, and local debit cards
- **Credit Cards** - Visa, MasterCard, and other international cards  
- **Net Banking** - Direct bank account transfers
- **UPI** - Unified Payments Interface for instant transfers
- **Digital Wallets** - URPAY and other supported wallet solutions

## Quick Start Checklist

Before you begin integration, ensure you have completed these essential steps:

::steps
### Merchant Onboarding
Complete the merchant onboarding process with Al Rajhi Bank to receive your payment gateway credentials and access.

### Receive Credentials
Download your integration credentials from the merchant portal:
- **Tranportal ID** - Unique merchant identifier
- **Tranportal Password** - Authentication password
- **Resource Key** - Encryption key for secure data transmission

### Environment Setup
Set up your development environment with:
- PHP 7.4+ or PHP 8.x
- SSL certificate for secure communication
- Database for transaction logging
- Web server with HTTPS support

### Test Integration
Use the sandbox environment to test your integration before going live.
::
