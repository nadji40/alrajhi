# Basics of Collecting Payments with ARB Payment Gateway

This section explains the fundamental payment collection process and how customers interact with Al Rajhi Bank Payment Gateway in your application.

## Payment Flow Overview

The payment collection process follows a simple, secure workflow:

::steps
### Customer Initiates Payment
A user adds goods & services to their cart and clicks the Al Rajhi Payment Gateway button in your application (the merchant's application).

### Checkout Process
A checkout form is displayed where the user fills in the payment details and authorizes the payment.

### Payment Processing
Al Rajhi Payment Gateway processes the payment using one of two integration methods:
- **Bank Hosted Setup**: Customer redirected to ARB's secure payment page
- **Merchant Hosted Setup**: Payment processed directly on your website

### Response Handling
After completion of a transaction, Al Rajhi Payment Gateway posts the response (success or failed) to a Callback URL defined by you (the merchant).

### Status Display
Based on the response received, you display the order status to the customer.

### Settlement
Receive payments collected from customers in your bank account on the next business day.
::

## Integration Methods

### Bank Hosted Setup

In this approach, customers are redirected to Al Rajhi Bank's secure payment page:

```php
// Example: Bank Hosted Payment Flow
class BankHostedPayment {
    private $gateway;
    
    public function __construct($gateway) {
        $this->gateway = $gateway;
    }
    
    /**
     * Initiate bank hosted payment
     */
    public function initiatePayment($orderData) {
        $paymentParams = [
            'amt' => $orderData['total_amount'],
            'currencyCode' => '682', // SAR
            'trackId' => $orderData['order_id'],
            'responseURL' => 'https://yoursite.com/payment-success',
            'errorURL' => 'https://yoursite.com/payment-error',
            'udf1' => $orderData['customer_id'],
            'udf2' => $orderData['order_reference']
        ];
        
        $response = $this->gateway->createPaymentToken($paymentParams);
        
        if ($response['success']) {
            // Redirect customer to ARB payment page
            $paymentURL = $response['paymentURL'] . '?paymentid=' . $response['paymentId'];
            return [
                'redirect_url' => $paymentURL,
                'payment_id' => $response['paymentId']
            ];
        } else {
            throw new Exception('Payment initialization failed: ' . $response['error']);
        }
    }
}
```

**Advantages:**
- Minimal development effort
- Maximum security (PCI compliance handled by ARB)
- Mobile-optimized payment interface
- Reduced integration complexity

### Merchant Hosted Setup

In this approach, payment is processed directly on your website:

```php
// Example: Merchant Hosted Payment Flow
class MerchantHostedPayment {
    private $gateway;
    
    public function __construct($gateway) {
        $this->gateway = $gateway;
    }
    
    /**
     * Process payment directly
     */
    public function processPayment($paymentData) {
        $transactionParams = [
            'amt' => $paymentData['amount'],
            'action' => '1', // Purchase
            'currencyCode' => '682',
            'trackId' => $paymentData['order_id'],
            'card_number' => $paymentData['card_number'],
            'expiry_date' => $paymentData['expiry_date'],
            'cvv' => $paymentData['cvv'],
            'cardholder_name' => $paymentData['cardholder_name']
        ];
        
        return $this->gateway->processDirectPayment($transactionParams);
    }
}
```

**Advantages:**
- Complete control over user experience
- Custom payment form design
- Real-time payment processing
- Advanced features support

## Payment Monitoring

### Real-time Transaction Tracking

Access real-time payment information through the merchant portal:

**Portal URL**: [https://digitalpayments.alrajhibank.com.sa/mrchptl/merchant.htm](https://digitalpayments.alrajhibank.com.sa/mrchptl/merchant.htm)

**Navigation Path**: Merchant Portal → Reports → Transaction Reports → Transaction Detail Report

### Transaction Status Verification

```php
// Example: Verify transaction status
class TransactionVerification {
    private $gateway;
    
    public function __construct($gateway) {
        $this->gateway = $gateway;
    }
    
    /**
     * Verify payment status after callback
     */
    public function verifyPayment($paymentId) {
        $statusResult = $this->gateway->getTransactionStatus($paymentId);
        
        if ($statusResult['success']) {
            $transactionData = $statusResult['data'];
            
            return [
                'verified' => true,
                'status' => $transactionData['result'],
                'amount' => $transactionData['amt'],
                'transaction_id' => $transactionData['tranid'],
                'track_id' => $transactionData['trackId']
            ];
        }
        
        return [
            'verified' => false,
            'error' => $statusResult['error']
        ];
    }
}
```

## Settlement Process

### Settlement Schedule

- **Standard Settlement**: Next business day for most transactions
- **Weekend Processing**: Special arrangements available
- **Holiday Schedule**: Modified settlement during bank holidays

### Settlement Verification

```php
// Example: Daily settlement reconciliation
class SettlementReconciliation {
    private $gateway;
    private $database;
    
    public function __construct($gateway, $database) {
        $this->gateway = $gateway;
        $this->database = $database;
    }
    
    /**
     * Reconcile daily settlements
     */
    public function reconcileSettlement($settlementDate) {
        $expectedTransactions = $this->getExpectedSettlement($settlementDate);
        $actualSettlement = $this->getActualSettlement($settlementDate);
        
        $reconciliation = [
            'date' => $settlementDate,
            'expected_amount' => array_sum(array_column($expectedTransactions, 'amount')),
            'actual_amount' => $actualSettlement['total_amount'],
            'transaction_count' => count($expectedTransactions),
            'discrepancies' => []
        ];
        
        // Check for discrepancies
        if ($reconciliation['expected_amount'] !== $reconciliation['actual_amount']) {
            $reconciliation['discrepancies'][] = [
                'type' => 'amount_mismatch',
                'expected' => $reconciliation['expected_amount'],
                'actual' => $reconciliation['actual_amount']
            ];
        }
        
        return $reconciliation;
    }
    
    private function getExpectedSettlement($date) {
        // Fetch successful transactions from your database
        return $this->database->getSuccessfulTransactions($date);
    }
    
    private function getActualSettlement($date) {
        // Fetch settlement data from bank or merchant portal
        return $this->gateway->getSettlementData($date);
    }
}
```

## Best Practices

### Security Considerations

1. **Always use HTTPS** for payment-related pages
2. **Validate all input data** before processing
3. **Store sensitive data securely** with proper encryption
4. **Implement proper session management**
5. **Log all payment transactions** for audit purposes

### Error Handling

```php
// Example: Comprehensive error handling
class PaymentErrorHandler {
    
    /**
     * Handle payment errors gracefully
     */
    public function handlePaymentError($error, $context = []) {
        // Log the error
        $this->logError($error, $context);
        
        // Determine user-friendly message
        $userMessage = $this->getUserFriendlyMessage($error);
        
        // Notify relevant parties if needed
        if ($this->isCriticalError($error)) {
            $this->notifyAdministrators($error, $context);
        }
        
        return [
            'success' => false,
            'user_message' => $userMessage,
            'error_code' => $error['code'] ?? 'UNKNOWN',
            'timestamp' => date('Y-m-d H:i:s')
        ];
    }
    
    private function getUserFriendlyMessage($error) {
        $messages = [
            'IPAY0100061' => 'Invalid payment amount. Please check and try again.',
            'IPAY0100119' => 'Invalid card number. Please verify your card details.',
            'IPAY0100042' => 'Payment session expired. Please try again.',
            'IPAY0100125' => 'Payment method not supported. Please try a different card.'
        ];
        
        return $messages[$error['code']] ?? 'Payment processing failed. Please try again or contact support.';
    }
    
    private function isCriticalError($error) {
        $criticalErrors = ['IPAY0200028', 'IPAY0100160', 'IPAY0100163'];
        return in_array($error['code'], $criticalErrors);
    }
    
    private function logError($error, $context) {
        error_log(json_encode([
            'timestamp' => date('Y-m-d H:i:s'),
            'error' => $error,
            'context' => $context
        ]), 3, 'payment_errors.log');
    }
    
    private function notifyAdministrators($error, $context) {
        // Send email or SMS notification to administrators
        // Implementation depends on your notification system
    }
}
```
