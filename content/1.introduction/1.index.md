# Introduction

Welcome to the Al Rajhi Bank Payment Gateway integration documentation. This comprehensive guide provides step-by-step procedures to integrate Al Rajhi Bank's payment gateway into your merchant application using REST APIs.

## About This Documentation

The Al Rajhi Bank Payment Gateway follows industry standards and norms as prescribed by MasterCard and Visa International, as well as conformity with Payment Card Industry - Data Security Standards (PCI-DSS).

This reference document is designed to help Al Rajhi Bank merchants integrate in a secure and compliant manner. Whether you're a system integrator, developer, or auditor, this documentation provides:

- **Technical integration details** including message formats for communicating with the Payment Gateway
- **Platform-agnostic guidance** that works regardless of your merchant platform
- **Best practices and recommendations** for secure payment processing
- **Comprehensive PHP code examples** for all integration scenarios

## Integration Options

Al Rajhi Bank Payment Gateway offers flexible integration options to suit different business needs:

### Bank Hosted Integration
- **Quick Implementation**: Minimal development effort required
- **Maximum Security**: Customers enter payment details on Al Rajhi Bank's secure pages
- **PCI Compliance**: Reduced PCI compliance scope for merchants
- **Mobile Optimized**: Responsive design for all devices

### Merchant Hosted Integration
- **Custom Experience**: Full control over payment form design and user experience
- **Advanced Features**: Support for card-on-file, recurring payments, and tokenization
- **3D Secure**: Built-in 3D Secure authentication for enhanced security
- **Real-time Processing**: Direct API communication for immediate transaction results

### Specialized Solutions
- **Apple Pay Integration**: Seamless mobile wallet payments
- **URPAY Wallet**: Support for local digital wallet solutions
- **Recurring Payments**: Automated subscription and billing management
- **Invoice Payments**: B2B payment processing capabilities
