# Troubleshooting

This section helps you identify and resolve common issues encountered during Al Rajhi Bank Payment Gateway integration. Use this guide to quickly diagnose problems and implement solutions.

## Common Integration Issues

### Connection and Authentication Problems

::card-group
  :::card
  ---
  icon: i-lucide-wifi-off
  title: Connection Timeout
  ---
  **Symptoms**: API requests timeout or fail to connect
  
  **Solutions**:
  - Verify your server's internet connectivity
  - Check firewall settings for outbound HTTPS connections
  - Ensure SSL/TLS 1.2+ support is enabled
  - Increase cURL timeout settings in your code
  :::

  :::card
  ---
  icon: i-lucide-key
  title: Authentication Failures
  ---
  **Symptoms**: Invalid credentials or authentication errors
  
  **Solutions**:
  - Verify Tranportal ID and Password are correct
  - Ensure Resource Key matches the one from merchant portal
  - Check if credentials are for the correct environment (sandbox/production)
  - Confirm credentials haven't expired
  :::

  :::card
  ---
  icon: i-lucide-lock
  title: Encryption/Decryption Issues
  ---
  **Symptoms**: Invalid encrypted data or decryption failures
  
  **Solutions**:
  - Verify Resource Key is exactly as provided
  - Ensure URL encoding before encryption
  - Check AES-256-CBC implementation
  - Validate IV (initialization vector) usage
  :::

  :::card
  ---
  icon: i-lucide-alert-circle
  title: Invalid Response Format
  ---
  **Symptoms**: Unexpected response structure or missing fields
  
  **Solutions**:
  - Check API endpoint URLs are correct
  - Verify request format matches documentation
  - Ensure proper JSON encoding/decoding
  - Validate required parameters are included
  :::
::

```php
// Common issue: Missing required parameters
$commonIssues = [

        'solution' => 'Ensure amt parameter is included and not empty'
    ],
    'invalid_currency' => [
        'error' => 'IPAY0100059',
        'description' => 'Transaction denied due to invalid currency code',
        'solution' => 'Use valid currency code (682 for SAR)'
    ],
    'invalid_track_id' => [
        'error' => 'IPAY0100063',
        'description' => 'Transaction denied due to invalid track ID',
        'solution' => 'Ensure trackId is unique and alphanumeric'
    ]
];

// Debug function to identify common issues
function debugPaymentToken($params) {
    $required = ['amt', 'action', 'currencyCode', 'trackId', 'responseURL'];
    $missing = [];
    
    foreach ($required as $field) {
        if (!isset($params[$field]) || empty($params[$field])) {
            $missing[] = $field;
        }
    }
    
    if (!empty($missing)) {
        return [
            'valid' => false,
            'missing_fields' => $missing,
            'message' => 'Missing required fields: ' . implode(', ', $missing)
        ];
    }
    
    return ['valid' => true, 'message' => 'All required fields present'];
}
```

#### Callback Handling Problems

```php
// Debug callback processing
function debugCallback($callbackData) {
    $debug = [
        'received_data' => $callbackData,
        'has_trandata' => isset($callbackData['trandata']) && !empty($callbackData['trandata']),
        'has_error' => isset($callbackData['Error']) || isset($callbackData['ErrorText']),
        'payment_id' => $callbackData['paymentid'] ?? 'Not provided',
        'transaction_id' => $callbackData['tranid'] ?? 'Not provided'
    ];
    
    // Log for debugging
    error_log('ARB Callback Debug: ' . json_encode($debug));
    
    return $debug;
}

// Example callback handler with debugging
function handleCallbackWithDebug($gateway, $callbackData) {
    $debug = debugCallback($callbackData);
    
    if (!$debug['has_trandata'] && !$debug['has_error']) {
        return [
            'success' => false,
            'error' => 'Invalid callback data - no trandata or error information',
            'debug' => $debug
        ];
    }
    
    return $gateway->handleCallback($callbackData);
}
```

## Error Code Reference

### Payment Processing Errors

The following table contains the most common error codes and their solutions:

| Error Code | Description | Solution |
|------------|-------------|----------|
| IPAY0100114 | Duplicate Record, transaction ID already exists | Use a unique trackId for each transaction |
| IPAY0100115 | Transaction denied due to missing original transaction id | Provide valid original transaction ID for refunds/voids |
| IPAY0100119 | Transaction denied due to invalid card number | Validate card number format and check digit |
| IPAY0100125 | Payment instrument not enabled | Contact Al Rajhi Bank to enable required payment methods |
| IPAY0100042 | Transaction time limit exceeds | Complete payment within the allowed time window |
| IPAY0100061 | Transaction denied due to invalid amount | Ensure amount is positive and in correct format |

### Integration Errors

| Error Code | Description | Solution |
|------------|-------------|----------|
| IPAY0100037 | Payment id missing | Include paymentId in status inquiry requests |
| IPAY0100050 | Invalid terminal key | Verify Tranportal ID and credentials |
| IPAY0100095 | Terminal inactive | Contact Al Rajhi Bank to activate your terminal |
| IPAY0200007 | Problem occurred while validating payment details | Check request format and required parameters |

## Debugging Tools

### Request/Response Logging

```php
class ARBDebugLogger {
    private $logFile;
    
    public function __construct($logFile = 'arb_debug.log') {
        $this->logFile = $logFile;
    }
    
    /**
     * Log API request
     */
    public function logRequest($endpoint, $requestData, $encryptedData = null) {
        $logEntry = [
            'timestamp' => date('Y-m-d H:i:s'),
            'type' => 'REQUEST',
            'endpoint' => $endpoint,
            'data' => $requestData,
            'encrypted' => $encryptedData ? 'YES' : 'NO'
        ];
        
        $this->writeLog($logEntry);
    }
    
    /**
     * Log API response
     */
    public function logResponse($endpoint, $responseData, $decryptedData = null) {
        $logEntry = [
            'timestamp' => date('Y-m-d H:i:s'),
            'type' => 'RESPONSE',
            'endpoint' => $endpoint,
            'data' => $responseData,
            'decrypted' => $decryptedData
        ];
        
        $this->writeLog($logEntry);
    }
    
    /**
     * Log error
     */
    public function logError($context, $error, $trace = null) {
        $logEntry = [
            'timestamp' => date('Y-m-d H:i:s'),
            'type' => 'ERROR',
            'context' => $context,
            'error' => $error,
            'trace' => $trace
        ];
        
        $this->writeLog($logEntry);
    }
    
    private function writeLog($entry) {
        $logLine = json_encode($entry, JSON_PRETTY_PRINT) . "\n" . str_repeat('-', 80) . "\n";
        file_put_contents($this->logFile, $logLine, FILE_APPEND | LOCK_EX);
    }
}

// Usage in your ARB gateway class
$logger = new ARBDebugLogger();

// Before making request
$logger->logRequest('/payment/token', $requestData, $encryptedTrandata);

// After receiving response
$logger->logResponse('/payment/token', $response, $decryptedData);
```

### Encryption Validation Tool

```php
/**
 * Test encryption/decryption functionality
 */
function testEncryption($resourceKey) {
    $testData = [
        'amt' => '100.00',
        'action' => '1',
        'trackId' => 'TEST_' . time()
    ];
    
    echo "Original data: " . json_encode($testData) . "\n";
    
    // Test encryption
    $gateway = new ARBPaymentGateway([
        'resource_key' => $resourceKey,
        'tranportal_id' => 'TEST',
        'tranportal_password' => 'TEST',
        'environment' => 'sandbox'
    ]);
    
    try {
        $encrypted = $gateway->encrypt($testData);
        echo "Encrypted: " . $encrypted . "\n";
        
        $decrypted = $gateway->decrypt($encrypted);
        echo "Decrypted: " . json_encode($decrypted) . "\n";
        
        if ($testData === $decrypted) {
            echo "Encryption/Decryption test PASSED\n";
            return true;
        } else {
            echo "❌ Encryption/Decryption test FAILED\n";
            echo "Expected: " . json_encode($testData) . "\n";
            echo "Got: " . json_encode($decrypted) . "\n";
            return false;
        }
    } catch (Exception $e) {
        echo "❌ Encryption test ERROR: " . $e->getMessage() . "\n";
        return false;
    }
}

// Run test
testEncryption('YOUR_RESOURCE_KEY');
```

## Performance Optimization

### Connection Pooling

```php
/**
 * Optimized HTTP client with connection reuse
 */
class ARBHttpClient {
    private static $curlHandle = null;
    
    public static function makeRequest($url, $data, $headers = []) {
        if (self::$curlHandle === null) {
            self::$curlHandle = curl_init();
            
            // Set persistent options
            curl_setopt_array(self::$curlHandle, [
                CURLOPT_RETURNTRANSFER => true,
                CURLOPT_SSL_VERIFYPEER => true,
                CURLOPT_SSL_VERIFYHOST => 2,
                CURLOPT_TIMEOUT => 30,
                CURLOPT_CONNECTTIMEOUT => 10,
                CURLOPT_HTTP_VERSION => CURL_HTTP_VERSION_1_1
            ]);
        }
        
        // Set request-specific options
        curl_setopt_array(self::$curlHandle, [
            CURLOPT_URL => $url,
            CURLOPT_POST => true,
            CURLOPT_POSTFIELDS => json_encode($data),
            CURLOPT_HTTPHEADER => array_merge([
                'Content-Type: application/json',
                'Accept: application/json'
            ], $headers)
        ]);
        
        $response = curl_exec(self::$curlHandle);
        $httpCode = curl_getinfo(self::$curlHandle, CURLINFO_HTTP_CODE);
        $error = curl_error(self::$curlHandle);
        
        if ($error) {
            throw new Exception("cURL Error: " . $error);
        }
        
        if ($httpCode !== 200) {
            throw new Exception("HTTP Error: " . $httpCode);
        }
        
        return json_decode($response, true);
    }
    
    public static function cleanup() {
        if (self::$curlHandle !== null) {
            curl_close(self::$curlHandle);
            self::$curlHandle = null;
        }
    }
}

// Register cleanup on script end
register_shutdown_function([ARBHttpClient::class, 'cleanup']);
```
