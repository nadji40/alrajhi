# Error Codes Reference

This comprehensive reference lists all known error codes from Al Rajhi Bank Payment Gateway, their descriptions, and recommended solutions.

## Common Error Codes

### Transaction Processing Errors

| Error Code | Description | Solution |
|------------|-------------|----------|
| **IPAY0100114** | Duplicate Record, transaction ID already exists | Use a unique trackId for each transaction |
| **IPAY0100115** | Transaction denied due to missing original transaction id | Provide valid original transaction ID for refunds/voids |
| **IPAY0100116** | Transaction denied due to invalid original transaction id | Verify the original transaction ID exists and is valid |
| **IPAY0100118** | Transaction denied due to card number length error | Ensure card number has correct length (13-19 digits) |
| **IPAY0100119** | Transaction denied due to invalid card number | Validate card number format and check digit |
| **IPAY0100120** | Transaction denied due to invalid payment instrument | Use supported payment methods only |
| **IPAY0100121** | Transaction denied due to invalid card holder name | Provide valid cardholder name (2-50 characters) |
| **IPAY0100122** | Transaction denied due to invalid address | Provide valid billing address |
| **IPAY0100123** | Transaction denied due to invalid postal code | Use valid postal code format |

### Amount and Currency Errors

| Error Code | Description | Solution |
|------------|-------------|----------|
| **IPAY0100060** | Transaction denied due to missing amount | Include amt parameter in request |
| **IPAY0100061** | Transaction denied due to invalid amount | Use positive numeric amount (e.g., "100.00") |
| **IPAY0100059** | Transaction denied due to invalid currency code | Use valid currency code (682 for SAR) |
| **IPAY0100062** | Transaction denied due to invalid Amount/Currency | Verify amount format and currency code match |

### Authentication and Configuration Errors

| Error Code | Description | Solution |
|------------|-------------|----------|
| **IPAY0100037** | Payment id missing | Include paymentId in status inquiry requests |
| **IPAY0100050** | Invalid terminal key | Verify Tranportal ID and credentials |
| **IPAY0100051** | Missing terminal key | Include Tranportal ID in request |
| **IPAY0100095** | Terminal inactive | Contact Al Rajhi Bank to activate terminal |
| **IPAY0100125** | Payment instrument not enabled | Enable required payment methods in merchant portal |
| **IPAY0100126** | Brand not enabled | Enable card brands (Visa/MasterCard) in portal |

### Session and Timeout Errors

| Error Code | Description | Solution |
|------------|-------------|----------|
| **IPAY0100042** | Transaction time limit exceeds | Complete payment within allowed time window |
| **IPAY0100040** | Transaction in progress in another tab/window | Close other payment windows and retry |
| **IPAY0100055** | Invalid Payment Status | Check payment status and retry if needed |

### Error Response Processor

```php
/**
 * Process and handle different types of error responses
 */
class ErrorResponseProcessor {
    private $errorHandler;
    
    public function __construct($errorHandler) {
        $this->errorHandler = $errorHandler;
    }
    
    /**
     * Process error response from ARB Payment Gateway
     */
    public function processErrorResponse($response, $context = []) {
        // Check for different error response formats
        
        // Format 1: Error in trandata (encrypted)
        if (isset($response['trandata']) && !empty($response['trandata'])) {
            try {
                $decryptedData = $this->decryptResponse($response['trandata']);
                
                if (isset($decryptedData['result']) && $decryptedData['result'] !== 'CAPTURED') {
                    return $this->handleTransactionError($decryptedData, $context);
                }
                
                if (isset($decryptedData['errorText'])) {
                    return $this->handleDecryptedError($decryptedData, $context);
                }
            } catch (Exception $e) {
                return $this->handleDecryptionError($e, $context);
            }
        }
        
        // Format 2: Direct error response
        if (isset($response['Error']) || isset($response['ErrorText'])) {
            return $this->handleDirectError($response, $context);
        }
        
        // Format 3: Status-based error
        if (isset($response['status']) && $response['status'] !== '1') {
            return $this->handleStatusError($response, $context);
        }
        
        // Unknown error format
        return $this->handleUnknownError($response, $context);
    }
    
    private function handleTransactionError($decryptedData, $context) {
        $result = $decryptedData['result'];
        $errorMappings = [
            'NOT CAPTURED' => 'IPAY0100061',
            'NOT APPROVED' => 'IPAY0100119',
            'DENIED BY RISK' => 'IPAY0100045',
            'HOST TIMEOUT' => 'IPAY0100160'
        ];
        
        $errorCode = $errorMappings[$result] ?? 'TRANSACTION_FAILED';
        return ARBErrorHandler::handleError($errorCode, $result, $context);
    }
    
    private function handleDecryptedError($decryptedData, $context) {
        $errorText = $decryptedData['errorText'];
        $errorCode = $this->extractErrorCode($errorText);
        
        return ARBErrorHandler::handleError($errorCode, $errorText, $context);
    }
    
    private function handleDirectError($response, $context) {
        $errorCode = $response['Error'] ?? 'UNKNOWN';
        $errorText = $response['ErrorText'] ?? 'Unknown error occurred';
        
        return ARBErrorHandler::handleError($errorCode, $errorText, $context);
    }
    
    private function handleStatusError($response, $context) {
        $status = $response['status'];
        $errorCode = 'STATUS_ERROR_' . $status;
        $errorText = "Invalid status response: {$status}";
        
        return ARBErrorHandler::handleError($errorCode, $errorText, $context);
    }
    
    private function handleUnknownError($response, $context) {
        $errorCode = 'UNKNOWN_ERROR_FORMAT';
        $errorText = 'Unknown error response format';
        
        return ARBErrorHandler::handleError($errorCode, $errorText, array_merge($context, [
            'response' => $response
        ]));
    }
    
    private function extractErrorCode($errorText) {
        // Extract error code from error text if present
        if (preg_match('/IPAY\d+/', $errorText, $matches)) {
            return $matches[0];
        }
        
        return 'EXTRACTED_ERROR';
    }

    }
}
```

## Error Prevention Strategies

### Input Validation

```php
/**
 * Comprehensive input validation to prevent common errors
 */
class ARBInputValidator {
    
    /**
     * Validate payment request parameters
     */
    public static function validatePaymentRequest($params) {
        $errors = [];
        
        // Validate amount
        if (!isset($params['amt']) || empty($params['amt'])) {
            $errors[] = 'Amount is required';
        } elseif (!is_numeric($params['amt']) || floatval($params['amt']) <= 0) {
            $errors[] = 'Amount must be a positive number';
        } elseif (floatval($params['amt']) > 999999.99) {
            $errors[] = 'Amount exceeds maximum limit';
        }
        
        // Validate currency code
        if (!isset($params['currencyCode'])) {
            $params['currencyCode'] = '682'; // Default to SAR
        } elseif (!in_array($params['currencyCode'], ['682', '840', '978'])) {
            $errors[] = 'Invalid currency code';
        }
        
        // Validate track ID
        if (!isset($params['trackId']) || empty($params['trackId'])) {
            $errors[] = 'Track ID is required';
        } elseif (strlen($params['trackId']) > 50) {
            $errors[] = 'Track ID too long (max 50 characters)';
        } elseif (!preg_match('/^[a-zA-Z0-9_-]+$/', $params['trackId'])) {
            $errors[] = 'Track ID contains invalid characters';
        }
        
        // Validate URLs
        if (!isset($params['responseURL']) || !filter_var($params['responseURL'], FILTER_VALIDATE_URL)) {
            $errors[] = 'Valid response URL is required';
        }
        
        if (isset($params['errorURL']) && !filter_var($params['errorURL'], FILTER_VALIDATE_URL)) {
            $errors[] = 'Invalid error URL format';
        }
        
        return [
            'valid' => empty($errors),
            'errors' => $errors,
            'sanitized_params' => $params
        ];
    }
    
    /**
     * Validate card details for merchant hosted integration
     */
    public static function validateCardDetails($cardData) {
        $errors = [];
        
        // Validate card number
        if (!isset($cardData['card_number']) || empty($cardData['card_number'])) {
            $errors[] = 'Card number is required';
        } else {
            $cardNumber = preg_replace('/\s+/', '', $cardData['card_number']);
            if (!self::isValidCardNumber($cardNumber)) {
                $errors[] = 'Invalid card number';
            }
        }
        
        // Validate expiry date
        if (!isset($cardData['expiry_date']) || empty($cardData['expiry_date'])) {
            $errors[] = 'Expiry date is required';
        } elseif (!self::isValidExpiryDate($cardData['expiry_date'])) {
            $errors[] = 'Invalid or expired card';
        }
        
        // Validate CVV
        if (!isset($cardData['cvv']) || empty($cardData['cvv'])) {
            $errors[] = 'CVV is required';
        } elseif (!preg_match('/^\d{3,4}$/', $cardData['cvv'])) {
            $errors[] = 'Invalid CVV format';
        }
        
        return [
            'valid' => empty($errors),
            'errors' => $errors
        ];
    }
    
    private static function isValidCardNumber($cardNumber) {
        // Luhn algorithm validation
        $sum = 0;
        $alternate = false;
        
        for ($i = strlen($cardNumber) - 1; $i >= 0; $i--) {
            $digit = intval($cardNumber[$i]);
            
            if ($alternate) {
                $digit *= 2;
                if ($digit > 9) {
                    $digit = ($digit % 10) + 1;
                }
            }
            
            $sum += $digit;
            $alternate = !$alternate;
        }
        
        return ($sum % 10) === 0;
    }
    
    private static function isValidExpiryDate($expiryDate) {
        if (!preg_match('/^(\d{2})\/(\d{4})$/', $expiryDate, $matches)) {
            return false;
        }
        
        $month = intval($matches[1]);
        $year = intval($matches[2]);
        
        if ($month < 1 || $month > 12) {
            return false;
        }
        
        $currentYear = intval(date('Y'));
        $currentMonth = intval(date('m'));
        
        if ($year < $currentYear || ($year === $currentYear && $month < $currentMonth)) {
            return false;
        }
        
        return true;
    }
}
```
