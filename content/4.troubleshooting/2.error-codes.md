# Error Handling

This section provides guidance on handling errors when integrating with Al Rajhi Bank Payment Gateway, based on the official documentation.

## Error Response Format  

According to the ARB Payment Gateway documentation, error responses follow this format:

### Failure Response Example

```json
[{
"status": "2",
"error": "IPAY0100124",
"errorText": "Problem occurred while validating transaction data",
"result": null
}]
```

### Success Response Example

```json
[{
"status": "1",
"result":"700212030953264091:https://securepayments.alrajhibank.com.sa/pg/URPaypage.htm",
"error":null,
"errorText": null
}]
```

## Error Response Processing

### Basic Error Handling

```php
<?php
function handleARBResponse($response) {
    $responseData = json_decode($response, true);
    
    if ($responseData['status'] == '1') {
        // Success
        return [
            'success' => true,
            'result' => $responseData['result']
        ];
    } else {
        // Error
        return [
            'success' => false,
            'error_code' => $responseData['error'],
            'error_message' => $responseData['errorText']
        ];
    }
}
```

## Comprehensive Error Handling

### Error Processing Function

```php
<?php
/**
 * Process ARB Payment Gateway errors based on official documentation
 */
function processARBError($response) {
    // Decode JSON response
    $responseData = json_decode($response, true);
    
    // Check response format
    if (!isset($responseData['status'])) {
        return [
            'success' => false,
            'error' => 'INVALID_RESPONSE_FORMAT',
            'message' => 'Invalid response format from payment gateway'
        ];
    }
    
    // Handle success (status = 1)
    if ($responseData['status'] == '1') {
        return [
            'success' => true,
            'result' => $responseData['result']
        ];
    }
    
    // Handle error (status = 2 or other)
    return [
        'success' => false,
        'error_code' => $responseData['error'] ?? 'UNKNOWN_ERROR',
        'error_message' => $responseData['errorText'] ?? 'Unknown error occurred',
        'status' => $responseData['status']
    ];
}

/**
 * Log errors for debugging and monitoring
 */
function logARBError($errorCode, $errorMessage, $context = []) {
    $logEntry = [
        'timestamp' => date('Y-m-d H:i:s'),
        'error_code' => $errorCode,
        'error_message' => $errorMessage,
        'context' => $context,
        'ip_address' => $_SERVER['REMOTE_ADDR'] ?? 'Unknown'
    ];
    
    error_log('ARB Payment Error: ' . json_encode($logEntry), 3, 'arb_errors.log');
}

/**
 * Get user-friendly error message
 */
function getUserFriendlyMessage($errorCode) {
    // Generic user-friendly messages
    $messages = [
        'INVALID_CARD' => 'Please check your card details and try again.',
        'INSUFFICIENT_FUNDS' => 'Transaction declined. Please check your account balance.',
        'EXPIRED_CARD' => 'Your card has expired. Please use a different card.',
        'INVALID_AMOUNT' => 'Invalid payment amount. Please try again.',
        'TIMEOUT' => 'Payment session expired. Please start over.',
        'SYSTEM_ERROR' => 'Payment service temporarily unavailable. Please try again later.'
    ];
    
    return $messages[$errorCode] ?? 'Payment processing failed. Please try again or contact support.';
}
```

### Callback Error Handling

```php
<?php
/**
 * Handle callback responses from ARB Payment Gateway
 */
function handleARBCallback($callbackData) {
    try {
        // Check if we have encrypted transaction data
        if (isset($callbackData['trandata']) && !empty($callbackData['trandata'])) {
            // Decrypt the response using your Resource Key
            $decryptedData = arbDecrypt($callbackData['trandata'], "YOUR_RESOURCE_KEY");
            
            // Check transaction result
            $result = $decryptedData['result'] ?? '';
            
            if (in_array($result, ['CAPTURED', 'APPROVED'])) {
                return [
                    'success' => true,
                    'transaction_id' => $decryptedData['transId'] ?? '',
                    'amount' => $decryptedData['amt'] ?? '',
                    'result' => $result
                ];
            } else {
                return [
                    'success' => false,
                    'error' => 'TRANSACTION_FAILED',
                    'result' => $result,
                    'message' => 'Transaction was not successful'
                ];
            }
        } else {
            // Handle direct error response
            return [
                'success' => false,
                'error' => $callbackData['Error'] ?? 'UNKNOWN_ERROR',
                'message' => $callbackData['ErrorText'] ?? 'Payment failed'
            ];
        }
    } catch (Exception $e) {
        // Handle decryption or processing errors
        logARBError('CALLBACK_PROCESSING_ERROR', $e->getMessage(), $callbackData);
        
        return [
            'success' => false,
            'error' => 'PROCESSING_ERROR',
            'message' => 'Failed to process payment response'
        ];
    }
}
```

## Input Validation

### Basic Request Validation

```php
<?php
/**
 * Validate ARB Payment Gateway request parameters
 */
function validateARBRequest($params) {
    $errors = [];
    
    // Validate required amount
    if (!isset($params['amt']) || empty($params['amt'])) {
        $errors[] = 'Amount is required';
    } elseif (!is_numeric($params['amt']) || floatval($params['amt']) <= 0) {
        $errors[] = 'Amount must be a positive number';
    }
    
    // Validate currency code (default to SAR)
    if (!isset($params['currencyCode'])) {
        $params['currencyCode'] = '682'; // SAR
    }
    
    // Validate track ID
    if (!isset($params['trackId']) || empty($params['trackId'])) {
        $errors[] = 'Track ID is required';
    } elseif (strlen($params['trackId']) > 50) {
        $errors[] = 'Track ID too long (max 50 characters)';
    }
    
    // Validate response URL
    if (!isset($params['responseURL']) || !filter_var($params['responseURL'], FILTER_VALIDATE_URL)) {
        $errors[] = 'Valid response URL is required';
    }
    
    return [
        'valid' => empty($errors),
        'errors' => $errors,
        'params' => $params
    ];
}

/**
 * Validate credentials before making requests
 */
function validateARBCredentials($config) {
    $errors = [];
    
    if (empty($config['tranportal_id'])) {
        $errors[] = 'Tranportal ID is required';
    }
    
    if (empty($config['tranportal_password'])) {
        $errors[] = 'Tranportal Password is required';
    }
    
    if (empty($config['resource_key'])) {
        $errors[] = 'Resource Key is required';
    }
    
    return [
        'valid' => empty($errors),
        'errors' => $errors
    ];
}
```

### Common Error Scenarios

Based on the response format, common error scenarios include:

- **Validation Errors**: Invalid request parameters
- **Authentication Errors**: Invalid credentials or inactive terminal
- **Transaction Errors**: Declined transactions or processing failures
- **System Errors**: Gateway timeouts or service unavailability

### Example Error Handling

```php
<?php
// Complete error handling example
function handlePaymentRequest($paymentData) {
    // 1. Validate input
    $validation = validateARBRequest($paymentData);
    if (!$validation['valid']) {
        return [
            'success' => false,
            'errors' => $validation['errors']
        ];
    }
    
    // 2. Process payment
    try {
        $response = sendARBRequest($paymentData, "YOUR_ENDPOINT_URL");
        return processARBError($response);
    } catch (Exception $e) {
        logARBError('REQUEST_FAILED', $e->getMessage(), $paymentData);
        return [
            'success' => false,
            'error' => 'SYSTEM_ERROR',
            'message' => 'Payment service temporarily unavailable'
        ];
    }
}
```
